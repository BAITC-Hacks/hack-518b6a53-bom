# Виджет сценариев развития Астаны

Интерактивная карта пяти районов с выбором мероприятий, предварительным просмотром их влияния и отчётами по городу и районам. Чистый HTML, CSS и JavaScript; расчёт выполняется в браузере. API и LLM не подключены, отчёты собираются локально по шаблонам.

## Запуск

Установите Node.js 22 или новее. Установка зависимостей не требуется.

```sh
node server.js
```

Откройте [http://localhost:4173](http://localhost:4173). Для разработки в Windows с перезапуском сервера при изменении файлов:

```sh
node --watch --watch-path=. server.js
```

После изменения файлов обновите страницу браузера. Проверка модели расчёта:

```sh
node --test
```

## Языки интерфейса

Переключатель RU / ҚАЗ / EN доступен на карте и в отчёте. Переводятся мероприятия, районы, показатели, подсказки и сообщения об ошибках. Переключение сохраняет текущий сценарий, фильтр и выбранный район отчёта; язык запоминается в браузере. По умолчанию используется русский.

Переводы находятся в `locales.js`, форматирование и хранение языка — в `i18n.js`. Интерфейс использует только системные шрифты (`Segoe UI`, Arial, sans-serif), без скачивания файлов и запросов к Google Fonts или другим сервисам шрифтов.

После обновления с версии без локализации перезапустите `npm start`, чтобы сервер начал отдавать новые модули переводов.

## Объекты на карте и объяснение результата

Нажмите на объект выбранного мероприятия или откройте его клавишей Enter/Space. Карточка показывает увеличенную иллюстрацию, стоимость, срок начала эффекта, изменения показателей района и совместные эффекты. Для городского мероприятия стоимость указана за весь город. Escape закрывает карточку и возвращает фокус на объект. На телефоне длинная карточка прокручивается, а кнопка закрытия остаётся сверху.

Размер объектов зависит от свободного места: подписи районов, соседние объекты и вода не перекрываются. В узкой Сарыарке при заполнении сценария используются более компактные объекты.

В отчёте есть вклад каждого мероприятия, сочетания с дополнительным бонусом и оставшиеся показатели ниже 40. На узком экране объяснения находятся во вкладке «Выводы». Вклад рассчитывается в `explainScenario` методом Шепли: усредняется разница результатов по всем порядкам добавления мер. Сумма вкладов совпадает с общим изменением до округления; совместные эффекты уже включены, повторно прибавлять их не нужно. Расчёт локальный, без запросов к ИИ. Карточки и объяснения доступны на RU / KK / EN.

## Локальная конфигурация OpenAI

Для дальнейшего подключения OpenAI скопируйте `.env.example` в `.env.local` и заполните `OPENAI_API_KEY`. Модель задаётся через `OPENAI_MODEL`; подготовлено значение `gpt-6-luna`.

Сервер автоматически загружает необязательный `.env.local` при запуске. Этот файл исключён из Git и недоступен через HTTP. Статический сервер отдаёт только публичные файлы виджета.

Конфигурация подготовлена для следующего этапа: обращения к OpenAI пока не реализованы, отчёты остаются локальными. Ключ используется только на сервере — не добавляйте его в браузерный JavaScript. См. [официальную инструкцию OpenAI](https://developers.openai.com/api/docs/quickstart).

## Расчёт и ограничения

Данные, веса и правила находятся в `model.js`. Все десять индикаторов измеряются по шкале 0–100, где больше означает лучше. Горизонт прогноза — 8 кварталов.

```text
Эффект меры = эффект из каталога × (8 − лаг) / 8
Балл района = Σ(вес индикатора × значение индикатора)
Средний балл = Σ(доля населения района × балл района)
Score = 0.7 × средний балл + 0.3 × минимальный балл района − N
```

`N` — количество значений индикаторов ниже 40 во всех районах. Эффекты суммируются, затем применяются синергии; итоговые значения ограничиваются диапазоном 0–100. Городская мера действует на каждый район, районная — только на выбранный.

- Ровно 5 разных мероприятий, бюджет не более 100 условных единиц.
- Не более 2 мероприятий одного направления.
- M1 и M3 несовместимы в одном сценарии.
- M4 и M7, а также M5 и M13 нельзя сочетать в одном районе.
- Синергии: M1 + M2 дают +2 к T1, M10 + M12 — +2 к B1, M5 + M6 — +2 к E2 в районе соответствующей локальной меры.

Базовый Score — **52.56**. Контрольный пример: M7, M8 и M10 в Нуре, M12 для города, M5 в Сарыарке. Стоимость — **95 ед.**, итоговый Score — **56.54**. Эти значения проверяются тестами.
